Nearest public-use airports
PLSS geometry: WA DNR public cadastre service, with a nationwide BLM cadastral fallback. Parcel geometry: Washington State Parcels Project (statewide) with per-county ArcGIS Online fallback. Address geocoding: U.S. Census Bureau geocoder with OpenStreetMap Nominatim fallback. Airport data: WSDOT non-military airports service, filtered to public-use client-side, with ArcGIS Online and static-list fallbacks. All data provided as-is; not a substitute for a recorded survey or official airspace data. Use "Run diagnostics" (top right) if lookups aren't working.
Service diagnostics
Tests each data source this tool depends on with a real request and reports pass/fail. If something fails, open its raw query link directly in a new tab — the browser will show the actual error (service moved, CORS block, etc.) which is far more diagnostic than anything JavaScript can see.
